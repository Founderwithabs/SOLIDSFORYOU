name: transcriber
description: Transcribes voice notes, podcasts, calls and videos into text and timestamped captions with OpenAI's Whisper, inside the chat, with nothing to install: just upload the file. Works for English, Hindi, Hinglish and 90+ languages; feeds video editing, YouTube chapters, Shorts and captions.

This lets the tool work in sessions opened inside this repository. The real
skill ships as a plugin. Read `plugins/transcriber/skills/transcriber/SKILL.md` and follow it.
Wherever that file refers to `SKILL_DIR` or to the skill's own folder, use
`plugins/transcriber/skills/transcriber` (relative to the repository root).
