---
name: publisher
description: Posts your finished Reels to your own Instagram account through Instagram's official API and reads back views, reach, likes and audience countries. Checks captions against Instagram's limits; never uses your password. Use for "post this to Instagram", Reel stats, or audience countries for a campaign.
---

This lets the tool work in sessions opened inside this repository. The real
skill ships as a plugin. Read `plugins/publisher/skills/publisher/SKILL.md` and follow it.
Wherever that file refers to `SKILL_DIR` or to the skill's own folder, use
`plugins/publisher/skills/publisher` (relative to the repository root).
